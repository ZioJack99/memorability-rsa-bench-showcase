# Data and method sources

[BOLD Moments, OpenNeuro ds005165 v1.0.4](https://openneuro.org/datasets/ds005165/versions/1.0.4), DOI [10.18112/openneuro.ds005165.v1.0.4](https://doi.org/10.18112/openneuro.ds005165.v1.0.4). Dataset terms: CC0. Official DataLad SHA-256 keys were verified for the response files.

Lahner et al. (2024), [Modeling short visual events through the BOLD moments video fMRI dataset and metadata](https://www.nature.com/articles/s41467-024-50310-3), Nature Communications, DOI 10.1038/s41467-024-50310-3.

Only aggregate evaluation summaries and original presentation figures are included here. No raw datasets, trained weights or third-party source code are redistributed. Underlying data/software retain their own terms.
